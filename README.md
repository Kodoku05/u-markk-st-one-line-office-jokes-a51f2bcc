A deterministic Node.js 22 program that writes one one-line office joke of at most
199 characters to `/output/entry.txt`. It uses only the standard library.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Without `MAKEFUN_OUTPUT_DIR`, output goes to `/output/entry.txt`.
